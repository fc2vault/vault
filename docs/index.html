What it does

A wall, a player,
a catalog.

Everything a tube site does for its own videos, done for the files on your disk. The filesystem is the source of truth; Vault never moves a file without a preview and never deletes one without asking.

Browse

Poster wall with real filters

Grid, by‑actress and list views. Filter by watched state, favorites, wishlist, HD, uncensored, studio, resolution, duration, cup size and age. Full‑text search across code, title, tags and actress names, aliases and Japanese included.

Watch

Streams straight from the share

HTTP range requests and sendfile, so seeks over SMB are instant. Multi‑part movies auto‑advance. HEVC plays natively where the browser can, with a clear fallback where it can't. Keyboard shortcuts for everything.

Scenes

Markers on the seek bar

Scenes sit on the timeline as chips you can hover and click, tube‑site style. Add, move and relabel them in training mode. A fine‑tuned video model proposes them for you; you only confirm or correct.

Catalog

Actresses with faces and stats

Every performer gets an overview: portrait, Japanese name, aliases, body stats, cup size, and her filmography with the titles you don't own yet as a wishlist. Reassign a misgrouped movie with one click.

Organize

Tidy the disk, safely

Normalize folders to <Actress>/<CODE>/<CODE>.mp4, quarantine junk, flag duplicates. Always a preview first. Deleted movies go to a recoverable trash, never to rm.

Anywhere

One page, phone to desktop

The same page adapts to a phone over your LAN or VPN: two‑column wall, a filter drawer, a stacked player. No separate app and nothing to install on the phone.

The player

Scene chips above the seek bar, the current scene named in the corner, tags and metadata beside the picture. Filmography of the performer on the left, so the next title is one click away.

The catalog

Portrait, Japanese name, measurements and aliases from the sources you enable, and everything you own by her in one place. Favorite, rename or merge from the same card.

On the phone

Same page, two columns.

Open Vault's address from any phone on your network and you get a two‑column wall, a filter drawer and a stacked player. Nothing to install on the phone, and nothing leaves your LAN.

Screenshots on this page come from a real library. Poster and video imagery is pixelated; the interface is as shipped.

The scene model

Trained on real reviews.
Updated every round.

Vault ships with a video classifier fine‑tuned on thousands of hand‑reviewed scene markers. It watches a movie in 6.4‑second windows and proposes where each act starts: blowjob, doggy, cowgirl, missionary, fingering, toy, creampie and more. You confirm or correct the proposals in the player and the markers land on the seek bar.

The model is actively maintained: each round is trained on a larger reviewed set and measured against the same held‑out performers, so every release is a verified step up. The newest build is a free download in Settings → Scene model, and the app tells you when there is a new one.

Tagging runs on a Mac with Apple Silicon or any machine with an NVIDIA GPU, offline. Nothing from your library leaves your network.

Privacy

Nothing leaves
your machine.

No cloud

A single Python process serves a single HTML page from your machine. Your library index, posters and catalog live in a folder next to it.

No account

Nothing to register. The only outbound traffic is the metadata scan you start yourself, and the model download you press the button for.

No telemetry

No analytics, no update pings, no crash reports. The source is open; read the whole server in one sitting.

LAN only

Vault has no login and no HTTPS on purpose. Use it on a trusted home network or over a VPN, and don't port‑forward it.

Install

Ten minutes,
no build step.

Vault is plain Python with no packages to install. You need Python 3.8 or newer, ffmpeg, and a modern browser.

Python 3.8+

Required. macOS: already there once the command‑line tools are installed. Windows: python.org, tick Add python to PATH. Linux: your package manager.

ffmpeg / ffprobe

Required. Makes posters and reads duration, resolution and codec. brew install ffmpeg, winget install ffmpeg, or apt install ffmpeg.

FlareSolverr

Optional. fc2ppv‑db sits behind a Cloudflare check; FlareSolverr clears it for you. A separate third‑party program, usually run in Docker. Without it you can paste a browser session instead.

Scene model

Optional. A ~450 MB download from Settings → Scene model. Tagging needs Apple Silicon or an NVIDIA GPU; viewing and editing markers needs nothing special.

Install ffmpeg

With Homebrew. If python3 asks to install the command‑line tools, say yes.

brew install ffmpeg

Get Vault

Either download Vault.app from the latest release and drop it into Applications, or clone the repo. The app asks for your library folder on first launch; the clone takes it on the command line.

git clone https://github.com/fc2vault/vault.git
cd vault
python3 serve.py --library "/Volumes/Movies"

Keep it running

Register Vault as a login item: it starts when you log in, restarts if it stops, and keeps running with no window open. Remove it again with --uninstall-service.

python3 serve.py --install-service
# then open http://127.0.0.1:8730/  — or http://<this-mac>:8730/ from your phone

Install Python and ffmpeg

Python from python.org (tick Add python to PATH in the installer), then ffmpeg in a terminal:

winget install ffmpeg

Get Vault

Download the latest release zip from GitHub and unpack it, for example to C:\Vault. Then in a terminal:

Keep it running

Register Vault as a scheduled task that runs at log on, without a console window. It appears in Task Scheduler as Vault; remove it with --uninstall-service.

# then open http://127.0.0.1:8730/

Windows support is new. If something breaks, open an issue with the message from server.log.

Clone the repo and point it at your movies. Updating later is a git pull.

Installs a systemd --user unit that starts at login and restarts on failure. On a headless server, also run loginctl enable-linger so it runs without a login session.

Questions

Fair questions.

Is it really all free?

Yes. The app, every metadata source, the bundled catalog and the scene model, with no movie limit and no key. Earlier versions had a paid tier; it was dropped in 1.7 because free is simpler for everyone. The terms are in LICENSE.md: use it, share it, don't sell it.

What do I get for supporting on Patreon?

The same Vault as everyone else, and my thanks. Contributions pay for the GPU time that trains each model round, the tooling and the hours behind every release, and supporters get an early look at what is coming and a say in what gets built next. Nothing is held back from people who don't contribute.

How does the scene model get onto my machine?

Settings → Scene model shows the newest build and a Download button. Vault fetches it from the project's GitHub releases into a per‑user folder, and vault‑scene‑tagger finds it there on its own. When a new round ships, the same tab offers the update.

Does the scene model need a GPU?

Tagging runs on Apple Silicon (MPS) at roughly 3× realtime, or much faster on any NVIDIA GPU. Reviewing markers in the player needs nothing special. The model runs entirely on your machine.

Which sources does it use for metadata?

fc2db.net, 123av and ffjav work out of the box. fc2ppv‑db, which supplies the cast and faces, sits behind a Cloudflare check, so it needs a pasted browser session or a FlareSolverr instance on your LAN.

Is this affiliated with FC2?

No. Vault is an independent, open‑source media manager for files you already own. It hosts nothing, links to no content, and includes no videos or images.
